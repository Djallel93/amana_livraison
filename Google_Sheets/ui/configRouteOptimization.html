⚙️ Optimisation des Routes

Configurer les paramètres d'optimisation

🗺️ Clustering Géographique
Livraisons à moins de X km = même cluster (recommandé : 3 km)
Clusters à moins de X km peuvent être groupés (recommandé : 15 km)
📍 Détection Livraisons Éloignées
Livraisons > X km du QG sont regroupées ensemble (recommandé : 30 km)
Avertissement si livraison > X km (recommandé : 50 km)
🚗 Capacités Véhicules
Poids maximum pour une berline (recommandé : 200 kg)
Poids maximum pour un break (recommandé : 400 kg)
ℹ️ Comment ça marche :
Le système utilise ces paramètres pour optimiser les routes :
• Regroupe les livraisons proches (clustering)
• Assigne les clusters aux véhicules selon leur capacité
• Détecte et alerte sur les trajets problématiques
• Maximise l'utilisation de chaque véhicule
